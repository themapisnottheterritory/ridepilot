# Glossary

- **Trip**: one rider's one-way ride, a pickup and a drop-off. A round trip is two trips (outbound and return), which can be on different runs.
- **Run**: one bus and driver for a day or shift, e.g. "UDR3, Thursday 8:00 AM - 5:00 PM". Dispatch puts trips on runs.
- **Manifest**: the ordered list of stops (pickups and drop-offs) for a run. The driver's tablet shows the published manifest.
- **Publish Manifest**: sends the current stop list to the driver's tablet. The red cloud icon on a run's panel on the Dispatch page means the manifest has changed and needs publishing.
- **Subscription Trip**: a standing, repeating trip (for example dialysis Monday/Wednesday/Friday). RidePilot creates the daily trips from it automatically.
- **Subscription Run**: a repeating run (for example Rgol1 every weekday). RidePilot creates each day's run from it automatically.
- **Unscheduled**: a trip not yet on any run. **Standby**: waiting for space. **Cab**: sent to a cab.
- **Demand response (DR)**: door-to-door trips booked by phone, run on runs like UDR1-10 (urban Victoria), RVIC, RGON, DeWitt, RCAL, MATA, JACK, and the county runs (Goliad Rgol1-5; Lavaca Hville1-4, Yoakum1-2, Gonzales1).
- **Fixed route**: the city bus routes (Blue, Gold, Green, Pink, Purple, Red, and Gold+Green on one-bus days) and the Inteplast commuter routes (Bay City, El Campo, Palacios, Edna, Port Lavaca, Victoria 1 and 2, and combined ones like Bay City + Palacios). Fixed-route runs never have trips on them; riders are counted as boardings at stops.
- **Paratransit**: ADA trips for riders certified ADA eligible, in Victoria.
- **PCA**: personal care attendant riding with a passenger (rides free).
- **Route Optimizer**: the "Optimize Route" button on a run that puts the stops in the best order.
