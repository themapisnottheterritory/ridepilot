# Runs: buses, drivers, hours

**Where**: **Runs** in the top menu lists runs by date (use the filters on the left, e.g. Service mode = Demand response, and the dates). Click View on a run to open it. The list can take a few seconds to load.

**Subscription runs**: the weekday runs are created automatically from **Subscription Run** templates (**View Subscription Run Templates** on the Runs page). Changing a template affects runs RidePilot creates from then on; runs already created for the coming weeks keep their old settings, so change those days one by one or ask GCRPC I.T. to update them all.

**Demand-response runs**: Monday-Friday. Rural runs (RVIC, RGON, DeWitt, RCAL, MATA, JACK, Goliad's Rgol and Lavaca's runs) are 7:00 AM - 4:00 PM. UDR runs (urban demand response, inside Victoria) are 8:00 AM - 5:00 PM: they must cover at least the fixed-route day, because the ADA requires it, so a day's UDR run may be made longer but never shorter.
- Victoria Transit: UDR1-10, RVIC1-3, RGON1-3, DeWitt1-3, RCAL1-3, MATA1-3, JACK1-3.
- Goliad County Rural Transit: Rgol1 (bus R8), Rgol2 (GOL 14), Rgol3 (GOL 15), Rgol4 (GOL 16), Rgol5 (GOL 18).
- Lavaca County Transit: Hville1 (LAV 38), Hville2 (LAV 45), Hville3 (LAV 47), Hville4 (LAV 49), Yoakum1 (LAV 52), Yoakum2 (LAV 53), Gonzales1 (LAV 54).
The bus listed is the anticipated vehicle; change it on the run when fleet assigns a different one.

**Bus and driver**: open the run, click **Edit**, choose the vehicle and the driver, save. A run needs both before trips can be assigned and before the manifest can be published. The run's start and end location comes from the bus's home garage automatically.

**Driver not available**: if RidePilot says the driver is unavailable, check the driver's availability hours (Drivers page, the driver's Recurring Availability) cover the run's hours.

**Split shift, or a hand-over to another driver (Split run)**: a driver can't be on two runs whose hours overlap, so to have someone drive UDR in the morning and DeWitt in the afternoon, cut each run at the hand-over. Open the run and click **Split run**. Pick the time, the new run's name (it suggests e.g. "UDR5 PM"), its driver and its bus. The page shows which trips stay and which move. The run keeps its driver, bus and the trips picked up before that time, and now ends then; the new run takes the rest of the hours and those trips, in the same order. Then do the same on the other run and put the first driver on its second half. Leave time between the two for the drive (Victoria to Cuero is about 35 minutes). A time that would leave a rider on board, or one after a trip that's already been picked up, is refused. If the manifest was published, both runs are published again and the tablets update. UDR has to run until 5:00 PM, so give the UDR half a driver. Only that day changes; the Subscription Run template doesn't.

**Don't make a run per rider**: a run is a bus's day, not one person's ride. Put a regular rider's trips on the day's run (a Subscription Trip for standing rides), rather than creating a run named after the rider.

**Undo a cancelled run (Revoke cancellation)**: on **Runs**, tick the cancelled runs, then **Apply Action to Selected Runs > Revoke cancellation**. Each run loses its **Cancelled** label, and if it is a recurring run, that weekday's recurring trips for the date go back on it (the ones still unassigned and not cancelled). Trips booked one at a time were taken off when the run was cancelled and RidePilot did not keep which run they were on, so put those back from **Dispatch**. Publish each run's manifest again afterwards. A run that was already started can't be revoked.

**Garages (where a bus lives, and where its runs start and end)**: **Vehicles > Garages** lists the agency's yards (Victoria office, Port Lavaca yard, Edna, Gonzales, Goliad office, Hallettsville office, ...). **Add a garage** needs a name and an address picked from the list as you type, which puts it on the map; it has to be inside the service area. A garage still used by a bus or an upcoming run can't be retired. To move a bus, open it and choose its **Garage**: every upcoming run of that bus that starts or ends at its garage moves with it, start and end stops included, and a run already on the driver's tablet today is updated there. Runs already started, and a start or end dispatch set to somewhere else, are left alone. "Other address (this bus only)" gives a bus an address of its own without changing the garage other buses share. For one run only, use **Change Locations** on the run's page and pick **Starts at** / **Ends at**.
